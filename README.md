# Easy Vertical Farming

An indoor farming prototype with environment and soil-moisture monitoring, servo watering and light sensing.

**Technology:** M5Stack and UIFlow.

## Run or inspect

Open the `.m5f` projects under `src` in a compatible M5Stack UIFlow environment. These are original Blockly/UIFlow project files, not Arduino sketches. Use the original M5Stack hardware and units for environment/soil sensing, servo watering and lighting. Existing public project/video references are in `docs/project-links.txt`. Hardware operation has not been tested.

## Repository preparation

Source and required assets were organised from existing coursework. Build outputs and IDE state are excluded. Original reports, slides and course handouts remain in the separate full backup; they are not bundled for public upload. Real credentials and original database records are not included.

## Validation status

The preparation checked file paths, Python syntax where applicable, structured files, credential removal and package integrity. Windows desktop apps, Flutter apps, hardware and online services have not been built or run in this environment.
